# 🍽️ Restaurant Management GUI (Java)

A mini project built using **Java GUI (Swing)** that simulates a restaurant ordering system.  
This project provides an interface where users can select and order food items with a simple bill system.

---

## 🧠 Features
- Interactive **Graphical User Interface**
- Menu with multiple food items (like burgers, pizza, etc.)
- Bill generation for selected items
- Clear and user-friendly layout

---

## 🛠️ Technologies Used
- **Java**
- **Swing GUI**

---

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `.java` file in any IDE (like IntelliJ, Eclipse, or VS Code).
3. Compile and run the program.
